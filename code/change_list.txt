SPTK 5.6.7 is now available for download. This is the first release of SPTK that used AI code reviews.
That allowed fixing several bugs and improving the code quality. There are also multiple performance improvements,
mostly in the network and database classes.
<p>
There are several new features in this release:
</p>
<p>
<ul>
  <li>Added Buffer::format() and Buffer::printf() methods.</li>
  <li>Added RedisConnect class that connects to Redis server.
      The class supports both synchronous and asynchronous Redis command execution.</li>
  <li>Added FastTCPServer class that uses an event-driven data model.
      The old TCPServer class that used a thread per connection model is removed.</li>
  <li>Added ReadWriteLock class that implements ReadLock, WriteLock, and supports lock promotion/downgrade.</li>
  <li>Added SocketObjectPool class with easy socket event management.</li>
  <li>Added thread safety in DateTime class.</li>
</ul>
</p>
